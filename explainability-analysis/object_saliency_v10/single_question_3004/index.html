MVP project · object-based saliency · pipeline test on one question · 5 Nov 2026

Object Saliency Test

One VSI-Bench question run end to end through the new pipeline, twice: once with object masks from OWLv2 + SAM 2 and once from SAM 3. Each run computes saliency maps for the v10 cross-attention model and the additive control (both seed 0, step 5,750) and two object-level measures built on them.

Result

  • The pipeline works. With SAM 3 the whole question takes 90 s on one B200 (masks 16 s, then about 20–35 s per model), against 2 min 36 s with OWLv2 + SAM 2. Only the job's own figure failed, because matplotlib isn't in the venv; this page draws the saved arrays instead.
  • SAM 3 gives clearly better masks. It finds the table, the answer, in 10 frames instead of 4 (the desk and the coffee table by the sofa), and the nightstand only by the bed, not on the dresser, armchair or picture. "Door" is still wrong in both: the TV cabinet and the shower curtain.
  • The masks changed the conclusion. With OWLv2 masks the table looked like the most salient object (2.07× in additive). With SAM 3 masks it drops to 1.34× in additive and 1.02× in cross-attention, which is no preference at all. The maps themselves barely moved between the runs (correlation 0.98–0.99), so this is the masks, not noise.
  • One signal held up. At layer 0, cross-attention between the sofa and the table is about 3× what the 3D bias alone would give, in both directions, with either masker. And in every case the geometry's saliency tracks Qwen's own visual saliency, so there is no object focus here that comes from the geometry itself.

The pipeline, step by step

1 · objects

Find the named objects

Parse the question for its objects and their roles: the reference (sofa) and the four candidates. Same parser as the v7 object-word study.

2 · masks

Mask them in every frame

Two maskers, same frames. A: OWLv2 boxes for "a photo of a {object}" (score ≥ 0.25, up to 3 per frame), each refined to a pixel mask by SAM 2. B: SAM 3, which segments every instance of a short text prompt directly (score ≥ 0.5, up to 3).

3 · cells

Pool onto the token grid

Each frame is 640×480, so Qwen sees it as 20×15 merged cells of 32×32 px. A mask becomes the fraction of each cell it covers.

4 · saliency

Attribute the answer

One backward pass of the answer margin through each model, read at the geometry injection and at Qwen's visual embedding.

5 · measures

Compare maps with masks

Object enrichment for both models, and object-to-object attention for the cross-attention model.

The maths

Cells and masks

There are N = 32 frames × 300 cells = 9,600 visual tokens. Token n is cell (t, r, c) in row-major order. For an object o with pixel mask Mo, its cell weight is the covered fraction:

f_o(n) = area(M_o ∩ cell n) / area(cell n) ∈ [0, 1]

Saliency

The target is the answer margin, the log-odds of the correct letter among the options: m = z_gt − log Σ_alt exp z_alt. Saliency at a point in the network is the gradient × input, with its norm over the 2,048 channels taken per token:

dest_k(n) = ‖ Δ_k,n ⊙ ∂m/∂Δ_k,n ‖₂ geometry added at decoder layer k ∈ {0, 1, 2} vis(n) = ‖ v_n ⊙ ∂m/∂v_n ‖₂ Qwen's own merged visual embedding additive: Δ_k,n = g_k,n (the projected VGGT feature of cell n) cross-attention: Δ_k,n = W_o Σ_j a_nj v_j (what cell n reads from every geometry token j) dest(n) = dest_0(n) + dest_1(n) + dest_2(n)

dest asks how much the answer depends on the geometry that arrives at cell n. vis asks the same about the image itself, which makes it the control for "objects are salient anyway".

Object enrichment

Over the frames Fo in which the object was detected, compare the share of saliency on the object with the share of area it covers:

share_o = Σ_n s(n) f_o(n) / Σ_n s(n) area_o = Σ_n f_o(n) / |cells in F_o| E_o = share_o / area_o (n over the cells of F_o; E = 1: no preference for the object)

A large mask caps E: an object covering a quarter of its frames can reach at most 4.

Object-to-object attention (cross-attention only)

Average the attention over the 16 heads, Ā = meanh softmax(q·k/√d + b), and spread object X's cells by their weight:

mass(X → Y) = Σ_i w_i Σ_j Ā_ij f_Y(j), w_i = f_X(i) / Σ f_X bias only: Ā⁰ = mean_h softmax_j( b_hij ), b_hij = −ν_h · min(‖x_i − x_j‖, 10) uniform: mass = Σ_j f_Y(j) / N (what attention spread evenly would give)

If learned exceeds bias only, the learned query–key scores send X's cells toward Y beyond what 3D proximity alone explains.

What the cross-attention is doing

Each visual cell asks "which geometry tokens of this video should I read?" Its attention weight on a key is exp(q·k/√d − ν·distance), normalised over all 9,600 keys. Two forces set it: the learned score q·k, which can point anywhere, and the 3D bias, which pulls attention toward nearby points. These charts show which force wins, layer by layer, and then follow the sofa's cells in this question.

A careful interpretation

  1. Masks decide object-level answers. With OWLv2 masks the table, the correct answer, looked like the most salient object in both models. With SAM 3, which finds it in 10 frames rather than 4, that mostly goes away: 1.34× in additive, 1.02× in cross-attention. A measure this sensitive to the detector needs the better detector and a check of every object class.
  2. The geometry follows the image. Under both maskers and in both models the vis ticks sit close to the dest bars, usually a little above them. Wherever the answer depends on the image, it also depends on the geometry added there, a little less. So this question shows no object focus that comes from the geometry itself, which is why vis has to be reported next to dest.
  3. Cross-attention spreads its saliency differently. With SAM 3 masks its largest enrichments are on the towel (1.85×) and the door (1.47×). Both have the weakest masks (the door includes the shower curtain), and the towel's 12 cells per frame make it sensitive to the 12% run-to-run variation in the cross-attention maps, so I wouldn't read anything into this yet.
  4. The learned scores matter now. The spread of q·k/√d (26, 31 and 56 in layers 0–2) exceeds the spread of the 3D bias (about 18), so the higher query–key learning rate in v10 made the learned part count, unlike v9. Even so, 67–83% of each cell's attention goes to cells in other frames that are more than one cell away in 3D, so this is far from a local operation.
  5. Sofa ↔ table attention is the one signal that held. At layer 0 with SAM 3 masks, sofa cells put 0.052 of their attention on table cells against 0.017 under the 3D bias alone (3.1×), and table cells put 0.068 on sofa cells against 0.022 (3.1×). Both are also above uniform attention. With OWLv2 masks the same pair stood out at layer 0 too. Layer 2 is mildly above the bias, layer 1 at it. This is the pair the question is about, which makes it the lead to test across the 180 object questions.
  6. One head has turned around. In layer 1 the smallest-ν head went from 0.1 to −0.09, so it now slightly prefers far keys. The others kept their spread from 0.13 to 6.3.

What to change before the full run

  • Use SAM 3 at score ≥ 0.5. It's faster and clearly more accurate here.
  • Fix or flag the weak classes. "door" picks up cabinets and shower curtains, and "towel" picks up cushions. Options: a more specific prompt ("room door"), a minimum mask area, or reporting these classes separately. Then check 20 masks by eye across several scenes.
  • Report vis next to dest every time, with the ratio Edest / Evis as the headline object measure for the geometry.
  • Expect noise of 6–12% in the maps between identical runs (bf16 on different GPUs: correlation 0.98–0.99, margins differing by up to 0.1). Single-question differences of that size mean nothing; the 180-question averages will.
  • Then run the plan: 179 object questions × the two models, now about 45 GPU-minutes with SAM 3.
