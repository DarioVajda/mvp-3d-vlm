# JEPA-style objectives for 3D / geometry / spatial reasoning and for cross-modal alignment with language models (2023–2026)

Scope note. "JEPA-style" here means: a predictor maps context embeddings to the embedding of a target; the target comes from a target encoder that is EMA, frozen, or stop-gradient; the loss is a regression in embedding space (L1 / smooth-L1 / L2 / cosine), optionally with an explicit anti-collapse regularizer; no reconstruction in pixel/point space. Several papers below are *not* self-labelled JEPA but match this recipe (Spa3R, Latent Denoising, GeoWorld-VLM); they are included and flagged. All arXiv ids were read from the papers' own pages (abstract page or HTML full text) unless marked "search snippet only / unverified". Date of research: 2026-10-26.

## Key question 1: Has any paper applied a JEPA-style loss between a language model's hidden states (or a VLM's visual tokens inside the LLM) and features from a frozen geometry / depth / 3D encoder?

### Takeaway
No paper found does exactly this (LLM-internal hidden states regressed onto frozen VGGT/DUSt3R/depth features). The closest matches are (i) Latent Denoising (arXiv 2604.21343), which regresses hidden states at an intermediate LLM layer onto the *frozen 2D vision encoder's* patch features (no geometry teacher), (ii) GeoWorld-VLM (2605.16713), which aligns *post-projector* (pre-LLM) image features with a frozen video world model by cosine loss with the LLM frozen, and (iii) Spa3R/Spa3-VLM (2602.21186), which uses frozen VGGT + DINOv3 as latent-prediction targets to pre-train a spatial encoder and then injects it into Qwen2.5-VL through cross-attention trained only with next-token loss. Spatial-VLM fusion papers that use VGGT directly (SpatialStack 2603.27437, VLM-3R) train with next-token loss only.

### Cited Findings
- Latent Denoising (Hong-style setup, LLaVA-1.5 + CLIP ViT-L/14@336 or SigLIP-SO400M, and Qwen-2.5-VL-7B): projected visual tokens are corrupted with a saliency-aware mixture of Gaussian noise (rate 0.10, tau_max 0.15) and masking (rate 0.02); a lightweight decoder reads hidden states at LLM layer 16 of 32 (ablation: layer 16 > 8 > 32) and regresses them onto the *frozen front-end vision encoder's* clean patch features; the reconstruction loss is MSE between L2-normalised vectors (cosine-equivalent), plus a relational KL over intra-image cosine-similarity rows and an intra-image InfoNCE with other corrupted tokens as negatives; all auxiliary losses apply only at corrupted positions; inference is unchanged (Sec. 3.1–3.3, 4.6). Teacher is frozen, no EMA — [arXiv 2604.21343 v2](https://arxiv.org/html/2604.21343v2)
- Latent Denoising results (Table 1, baseline -> method): LLaVA+SigLIP GQA 62.1->64.3, VQAv2 76.3->78.6, MMBench 64.5->68.7, TextVQA 49.6->54.1 (18/18 benchmarks improve); Qwen-2.5-VL GQA 60.2->64.6, MMBench 83.1->84.5 (17/18); LLaVA+CLIP MME 1879->1846 (a decline). No depth / 3D / spatial benchmark; the paper does not mention JEPA; DINOv2 appears only as a CKA reference — [arXiv 2604.21343 v2](https://arxiv.org/html/2604.21343v2)
- GeoWorld-VLM: teacher = frozen camera-conditioned image-to-video model LingBot-World-Fast, features from DiT block 24 after two denoising steps (Sec. 3.2, 4.1, App. B); student = post-projector image features P(V(x)) (Sec. 3.3); loss L_align = 1 − cos(u_s/‖u_s‖, u_t/‖u_t‖) (Eq. 5) through separate 2-layer MLP heads (hidden 1024, out 512); a preservation loss (Eq. 6, squared L2 to a frozen copy of the original VLM vision side) with λ_align = 0.10, λ_preserve = 0.05; task loss = option-letter cross-entropy; *the LLM is frozen* and only encoder + projector + heads update (Sec. 3.1, 3.5) — [arXiv 2605.16713 v2](https://arxiv.org/html/2605.16713v2)

- LLM-JEPA (Huang, LeCun, Balestriero): loss L = Σ next-token CE + λ·d(Pred(Enc(Text)), Enc(Code)) (Eq. 2); Enc = last-layer hidden state of the last token; the predictor is the *same* LLM with k ∈ {0..4} appended [PRED] tokens (tied weights); d is cosine similarity; both views are packed in one context with a block attention mask so neither view attends to the other; no stop-gradient or EMA is mentioned; text-only (NL->regex, GSM8K, Spider). - "Representation Without Reward: A JEPA Audit for LLM Fine-Tuning" (Sengupta): 22 training-time auxiliaries incl. a decoder-visible JEPA term on Llama-3.2-1B-Instruct + LoRA, NL->regex; the JEPA auxiliary is the first with a positive gradient cosine to cross-entropy, but exact-match stays within seed noise; full fine-tuning replication (n=5) Δ = +0.04 pp (TURK, p=0.96), +0.52 pp (SYNTH, p=0.28); author calls it a "structured null" — [arXiv 2605.15394](https://arxiv.org/abs/2605.15394)
- Spa3-VLM: Spa3R Encoder (frozen) latent z (256 queries, 768-d) is projected by a 2-layer projector to the 2048-d VLM space and used as *keys/values*; the *queries are the VLM's native visual tokens F_V*, not LLM hidden states; 16-head cross-attention + LayerNorm + gated 2-layer MLP (512 bottleneck), zero-initialised output, residual fusion; the adapter and the LM are trained (1 epoch, lr 1e-5), VLM vision encoder frozen; cross-attention adapter 58.6 vs sequence-appending 51.1 on VSI-Bench average (Table VI) — [arXiv 2602.21186 v2](https://arxiv.org/html/2602.21186v2)

- SpatialStack (CVPR 2026): frozen VGGT patch tokens from layers 11, 17, 23 are reordered, RMS-normalised, 2x2-merged, MLP-projected and *added as residuals* at LLM layers 0, 1, 2 on the visual-token positions (Eq. 5); training loss is next-token cross-entropy only — "no auxiliary objectives or task-specific losses are introduced" (Sec. 4.2); VSI-Bench 67.5 (Qwen3.5-based 5B), 60.9 (Qwen2.5-VL-based 4B) vs Cambrian-S-3B 57.3 (Fig. 5) — [arXiv 2603.27437 v3](https://arxiv.org/html/2603.27437v3)
- JEPA-VLA: frozen V-JEPA 2 encoder features (two most recent frames) enter OpenVLA-OFT via Flamingo-style gated cross-attention every 8 decoder layers with *VLA tokens as queries and V-JEPA 2 features as keys/values*, or via linear projection + concatenation for a Chameleon-based VLA; no latent-predictive loss during VLA training (action L1 only) — [arXiv 2602.11832 v1](https://arxiv.org/html/2602.11832v1)
- KAIST "geometric distillation" (2506.09883): distils sparse correspondences, relative-depth relations and dense cost volumes from MASt3R / VGGT into a pretrained VLM's vision side without architecture change; abstract gives no numbers and does not describe a latent regression loss — [arXiv 2506.09883](https://arxiv.org/abs/2506.09883) (abstract only; loss details unverified)
- "Distilling 3D Spatial Reasoning into a Lightweight VLM with CoT" (2605.09719) uses VGGT as the student's vision encoder with a multi-task distillation pipeline from a 7B 3D-VLM teacher; no JEPA-style latent objective mentioned; retains 54–72% of teacher performance on ScanNet / 3D-FRONT — [arXiv 2605.09719](https://arxiv.org/abs/2605.09719) (abstract only)

### Inferences
- The literature splits cleanly: (a) latent-prediction *inside* the LLM has only been done with the VLM's own 2D encoder as teacher (Latent Denoising) or text-only (LLM-JEPA); (b) geometry teachers (VGGT/DINOv3) have been used as latent-prediction targets only *outside* the LLM (Spa3R), and are then wired in by cross-attention or residual addition under next-token loss alone. A VGGT-target JEPA loss on LLM-internal visual-token hidden states appears to be unoccupied ground.
- Two independent VLM papers (Latent Denoising, GeoWorld-VLM) found that the alignment is best applied at or before the middle of the stack (layer 16/32; post-projector) and that a cosine / normalised-MSE loss is sufficient when the teacher is frozen — no EMA was needed in either.
- Spa3R's Table IV shows that *combining* a geometry teacher (VGGT) with a semantic teacher (DINOv3) as latent-prediction targets beats either alone by 1–2 VSI-Bench points, and that latent-predicted features (58.6) beat raw VGGT features injected by the same adapter (55.1).
- The GeoWorld-VLM SAT ego-motion result (DINOv3 distillation 63.78 vs world-model teacher 52.43) is a warning that teacher choice can reverse results per sub-task.

### Gaps
- No paper found with a VGGT / DUSt3R / depth-encoder teacher and the LLM's own hidden states as the student (searched: "JEPA language model hidden states", "latent prediction loss align vision tokens LLM hidden states frozen DINOv2 VGGT", "VGGT DUSt3R teacher distillation ... vision-language model").
- The KAIST geometric-distillation paper's exact losses and numbers were not extracted (abstract page only).
- SpatialStack's VLM-3R comparison numbers were not in the fetched part of the page.

## Key question 2: Point-JEPA, 3D-JEPA, and other JEPAs for point clouds / depth / multi-view — what exactly do they predict, and do any use a frozen teacher (VGGT, DINOv2, DUSt3R)?

### Takeaway
Point-JEPA, 3D-JEPA and AD-L-JEPA are single-modality I-JEPA ports (context point/BEV patches -> EMA-or-teacher features of masked patches). CrossJEPA is the only 3D JEPA with a frozen 2D foundation-model teacher (DINOv2 ViT-B/14, global per-view targets). Spa3R is the only work found that uses frozen VGGT (and DINOv3) as patch-level latent-prediction targets; no JEPA-style paper uses DUSt3R.

### Cited Findings
- Point-JEPA (Saito et al., WACV 2025): target encoder = EMA of context encoder, τ 0.995 -> 1.0 (Sec. 3.3, App. A); context/target encoders are 12-layer, width-384 Transformers with a mini-PointNet patch embedder; predictor depth 6, width 192, mask tokens = shared learnable vector + positional encoding from target centre points (Sec. 4.1); loss = smooth-L1 (β=2) averaged over M=4 target blocks (Eq. 2); targets are taken *after* the target encoder's Transformer; a greedy nearest-centre "sequencer" orders patches so contiguous blocks can be selected; pretrained on ShapeNet (41,952 shapes), ~7.5 h on one RTX A5500. No loss-type ablation; collapse not discussed beyond EMA; no frozen teacher — [arXiv 2404.16432 v6](https://arxiv.org/html/2404.16432v6)
- Point-JEPA results: ModelNet40 linear SVM 93.7 ± 0.2 (Table 1); fine-tune ModelNet40 94.1 ± 0.1 w/ voting (Table 2); ScanObjectNN OBJ-BG 92.9 ± 0.4, OBJ-ONLY 90.1 ± 0.2, PB-T50-RS 86.6 ± 0.3 (Table 2); few-shot 5w10s 97.4 ± 2.2, 5w20s 99.2 ± 0.8, 10w10s 95.0 ± 3.6, 10w20s 96.4 ± 2.7 (Table 3); ShapeNetPart mIoU_C 83.9 / mIoU_I 85.8 (Table 5, below SOTA). - 3D-JEPA (Hu et al.): one context block (scale 0.85–1.0, target-overlapping tokens removed) predicts several target blocks (FPS centres + KNN, scale 0.15–0.2) within the same point cloud (Sec. ### Inferences
- Within-modality 3D JEPAs converge on: EMA target with momentum ramped 0.995/0.996 -> 1.0, a narrow shallow predictor (6 x 192 to 12 x 384), and smooth-L1 or cosine in latent space; results on ModelNet40/ScanObjectNN cluster within ~1 point of each other and of MAE-style baselines, so the objective itself is not a large accuracy lever at object scale.
- The two works with frozen teachers (CrossJEPA with DINOv2, Spa3R with VGGT+DINOv3) both dropped EMA and masking entirely and report no collapse; CrossJEPA's App. A documents collapse precisely when an EMA-updated *image* branch was added. This is direct evidence that a frozen geometry/semantic teacher removes the need for EMA machinery.
- CrossJEPA's targets are global per-view embeddings, so it provides no evidence about patch-level 2D<->3D correspondence; Spa3R does patch-level targets but by *rendering the target view's feature map*, i.e., correspondence is established by camera geometry, not by token matching.

### Gaps
- No JEPA-style paper found using DUSt3R/MASt3R features as latent targets.
- 3D-JEPA's teacher update rule (EMA vs frozen dVAE) is ambiguous in the text; the HTML says "dVAE tokens from the tuned 3D autoencoder" but also calls it a teacher. Treat as unverified.
- No scene-level (ScanNet / indoor occupancy) JEPA found; Point-JEPA lists scene segmentation/detection only as future work.
- Le MuMo JEPA numeric results not extracted (abstract page only).

## Key question 3: VL-JEPA (arXiv 2512.10942): what does it predict, how is text handled, and has it or anything like it been used for spatial / 3D QA?

### Takeaway
VL-JEPA predicts a *pooled text embedding of the answer* from (frozen V-JEPA 2 ViT-L video tokens + tokenised text query), through a predictor initialised from Llama-3.2-1B layers, trained with bidirectional InfoNCE against a trainable EmbeddingGemma-300M target encoder; it has no patch-level correspondence, no EMA, and no spatial/3D/depth evaluation. Nothing like it has been reported on VSI-Bench or other 3D QA.

### Cited Findings
- Architecture (Sec. 3.1): X-Encoder = frozen V-JEPA 2 ViT-L (304M), 256² frames, images duplicated to video shape; Y-Encoder = EmbeddingGemma-300M, *trainable* with lr multiplier 0.05, context 512; Predictor = last 8 Transformer layers of Llama-3.2-1B (490M trainable), Llama tokenizer/embeddings, causal mask removed so visual and query tokens attend jointly (causal attention costs −1.9 VQA points, Table 7d); average pooling over non-[PAD] predictor tokens gives the predicted embedding; linear heads map predictor and Y-Encoder into a shared 1,536-d space. The paper is internally inconsistent on which Llama layers (Sec. 3.1 "last 8" vs Table 7d default "Layer 8-16") — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- Loss (Sec. 2): bidirectional InfoNCE between normalised predicted and target embeddings, applied to predictor and Y-Encoder jointly; collapse is prevented by InfoNCE's uniformity term (citing Wang & Isola 2020); VICReg / SIGReg left as future work. Loss ablation (Table 7c; classification / retrieval / VQA): InfoNCE 23.3 / 30.3 / 44.3; cosine 16.5 / 20.2 / 46.6; L1 14.8 / 15.5 / 41.9; L2 13.5 / 11.7 / 43.7. "Only InfoNCE provides anti-collapse regularization when the Y-Encoder is unfrozen"; a frozen text encoder + linear projection variant is ablation (e) — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- Text handling (Sec. 2, 3.1, 4.2, 4.5): text query is tokenised and fed into the predictor alongside visual tokens; the target text (caption / answer / label) is encoded by the Y-Encoder; classification and discriminative VQA are done by nearest-embedding matching of candidate answers; a lightweight Y-Decoder translates predicted embeddings to text only at inference, enabling selective decoding at 0.35 Hz that matches uniform 1 Hz decoding (~2.85x fewer decode ops; Fig. 4, EgoExo4D CIDEr) — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- Data / stages (Sec. 3.2): Stage 1 query-free pretraining on Datacomp + YFCC-100M (image-text) and Action100M (video-text), batch 24k, 100k iters (2B samples), then 8-frame (60k) and 32-frame (10k) video; ~4 weeks on 24 x 8 H200; Stage 2 SFT on the PLM mixture (25M VQA, 2.8M captioning, 1.8M classification), 83k steps, batch 3,072 — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- Results: zero-shot avg classification over 8 datasets 52.5 (VL-JEPA_BASE) vs PE-Core-G 44.7; avg retrieval R@1 63.7 vs 58.1 (Table 1); VL-JEPA_SFT (1.6B) GQA 61.5, TallyQA 69.9, POPE 85.7, POPEv2 86.3, "on par" with InstructBLIP / Qwen-VL (Table 2, with InternVL-Chat higher on GQA at 66.6); controlled comparison vs token-space VLM with same Perception Encoder and data: at 15M samples 14.8 CIDEr / 41.0% top-5 vs 7.1 / 27.2 (Sec. 4.5, Fig. 3); EPIC-KITCHENS-100 R@5 34.2 vs V-JEPA 2 ViT-L 32.7 (ViT-g 39.7) (Tables 4–5); WorldPrediction-WM 65.7 (Table 3). PerceptionTest is not reported — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- No spatial, 3D, depth or embodied-QA benchmark is evaluated; the predictor uses bidirectional *self*-attention over concatenated visual+query tokens, with no separate cross-attention module and no discussion of keys/values — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- VL-JEPA weaker on appearance-centric datasets (Kinetics-400, COIN task recognition) (Sec. 4.1 discussion) — [arXiv 2512.10942 v2](https://arxiv.org/html/2512.10942v2)
- VL-JEPA is listed as an ICLR 2026 poster — [ICLR 2026](https://iclr.cc/virtual/2026/poster/10006956) (search result; not fetched)

### Inferences
- VL-JEPA's "JEPA" is really a text-embedding-regression VLM with a contrastive loss; its only latent-regression ablations (L1/L2) performed clearly worst for classification/retrieval, which the authors attribute to lack of anti-collapse regularisation once the target encoder trains. With a *frozen* target encoder (as in a VGGT-teacher setting) that argument does not apply, and their cosine variant was actually best on VQA.
- Because the predictor is Llama layers with the causal mask removed, VL-JEPA is the closest existing demonstration that LLM Transformer layers can serve as a JEPA predictor over mixed visual+text tokens.

### Gaps
- No spatial or 3D QA evaluation exists for VL-JEPA or any derivative; searches for "VL-JEPA VSI-Bench" / "JEPA 3D question answering" returned nothing.
- The Y-Decoder architecture and whether it is an LLM are not specified in the extracted text.

## Key question 5: Cross-modal JEPAs (audio-visual, text-image, RGB-depth, remote sensing) — and do any make the predicted embeddings serve as attention keys/values?

### Takeaway
Cross-modal JEPAs exist for audio-video (MJEPA), text-image (TI-JEPA, AlignJEPA, M3-JEPA), image->3D (CrossJEPA), RGB->depth (Depth-Regularized JEPA, Le MuMo) and SAR<->optical (CR-JEPA). Most predict *pooled* cross-modal embeddings (no token correspondence) and add a contrastive or SIGReg term when the target encoder is not frozen. No paper found uses the JEPA-predicted embeddings themselves as attention keys/values inside an LLM; cross-attention appears only as a predictor/aligner module (TI-JEPA, 3D-JEPA) or as the downstream fusion path for frozen JEPA features (JEPA-VLA, Spa3-VLM).

### Cited Findings
- MJEPA (Teotia, Bardes, Rabbat, Chopra, Muckley, Ballas; Meta): single shared ViT encoder for audio and video; EMA target (cosine 0.999 -> 1.0 for ViT-L, constant 0.999 for scaled models); one shared intra-modal narrow (384-d) ViT predictor fed multi-level encoder features (layers {5,11,17,23} for ViT-L) via a 2-layer MLP + mask tokens + modality/positional embeddings; cross-modal predictors are separate 3-layer MLPs on *mean-pooled* last-layer features because "there is no natural token-level correspondence between audio and video"; L1 loss throughout; stop-gradient + EMA as safeguards. Ablation (AudioSet-20K frozen mAP, A / V / A-V): unimodal baselines 30.87 / 19.84 / –; shared encoder intra-modal only 28.70 / 17.90 / 32.38; + cross-modal alignment 33.52 / 19.58 / 36.34; full MJEPA ViT-L 38.89 / 25.38 / 42.90; ViT-g + data scaling 40.97 / 29.82 / 45.44. ESC-50 96.9%, FSD50K 65.8 mAP, K400 85.0, SSv2 73.9. No LLM, no key/value sharing — [arXiv 2606.25225](https://arxiv.org/html/2606.25225)
- M3-JEPA (Geely AI Lab / PKU / SIAT): frozen encoders (LLaMA-3-8B text, DINOv2-L image, LanguageBind audio) with LoRA rank 64 on three layers each; predictor = multi-gate MoE (12 experts, top-4, 2 gates, 2048 hidden); loss = L2 regression + in-batch cosine contrastive, α = 0.5 (Eqs. 9–11); collapse argued information-theoretically (contrastive term maximises MI, regression term reduces conditional entropy; Sec. 4.1), no explicit mechanism; results: COCO R@1 87.7 / 89.7 (Table 1), ImageNet-1K 86.6 vs DINOv2 83.2 (Table 3), VQAv2 test-dev 82.3 (Table 4, behind BEiT-3); cross-modal attention only listed as future work; LLaMA is used as a frozen text encoder, not as a generator — [arXiv 2409.05929 v6](https://arxiv.org/html/2409.05929v6)
- TI-JEPA (Vo et al.): frozen I-JEPA ViT-H image encoder and frozen gte-base text encoder; two text-to-image cross-attention blocks (X on the context path, X̃ on the target path), each = self-attention + cross-attention with text + MLP; the I-JEPA predictor predicts masked *image patch* embeddings conditioned on text; the paper lists an EMA momentum schedule 0.996 -> 1.0 but does not say which network it updates; loss described as average L1 in text but written as squared L2 in the equation (Sec. 3.3); freezing "mitigates energy collapse"; MVSA-Single acc/F1 76.75 / 74.62, MVSA-Multi 77.55 / 75.02 (Table 4; CLMLF F1 76.00 higher on Multi). Which side provides queries vs keys/values is not stated; no LLM — [arXiv 2503.06380 v1](https://arxiv.org/html/2503.06380v1)
- AlignJEPA (remote sensing): frozen AnySat vision encoder and frozen RemoteCLIP text encoder; a ~20M-parameter predictor (512-d, fine/2x2-regional/global pooled tokens + scale embeddings, 6-layer 8-head transformer, single learned pooling query, L2-normalised) maps partially visible image tokens to one caption embedding; loss = (1 − cos) + λ·multi-positive bidirectional InfoNCE (τ = 0.07, λ = 1); no patch-to-word supervision; no explicit collapse mechanism beyond frozen targets + contrastive term. BigEarthNet.txt T2I/I2T R@1 20.72 / 21.89 vs contrastive-only aligner 16.90 / 17.80 (Table 1); RSVQA-LR probe 91.84% vs 86.57% (Table 3, below RSGPT 92.29%); ablation mean R@1: full 21.31, contrastive-only 17.75, prediction-only 18.80, no masking 18.75, linear projection 11.20 (Table 4). No LLM — [arXiv 2608.15456](https://arxiv.org/html/2608.15456)
- CR-JEPA (remote-sensing retrieval): modality-specific stems + shared transformer trunk; JEPA-style masked latent prediction within and across modalities; SIGReg (from LeJEPA) on retrieval projections; BEN-14K S1->S2 61.23% -> 75.82% and S2->S1 63.73% -> 75.40% over X-JEPA — [arXiv 2606.00706](https://arxiv.org/abs/2606.00706) (abstract only; target-encoder type unverified)
- CrossJEPA, Depth-Regularized JEPA, Le MuMo JEPA: see KQ2 (image->3D with frozen DINOv2; RGB->stop-grad depth with cosine + SIGReg; RGB+LiDAR fusion tokens with SIGReg).
- 3D-JEPA's context-aware decoder uses the *context* representation as keys/values for cross-attention from target mask tokens (Sec. - Downstream (non-JEPA-loss) uses of JEPA-pretrained features as cross-attention K/V: JEPA-VLA (VLA tokens as Q, frozen V-JEPA 2 features as K/V, gated, every 8 layers of OpenVLA-OFT) — [arXiv 2602.11832 v1](https://arxiv.org/html/2602.11832v1); Spa3-VLM (VLM visual tokens as Q, Spa3R latents as K/V; cross-attention 58.6 vs appending 51.1 on VSI-Bench) — [arXiv 2602.21186 v2](https://arxiv.org/html/2602.21186v2); JEPA Guided Diffusion (Q-Former queries over V-JEPA 2.1 features projected to Llama-3.2-1B width) — [arXiv 2609.21379](https://arxiv.org/html/2609.21379)

### Inferences
- Whenever the cross-modal target encoder is trainable (VL-JEPA, M3-JEPA, AlignJEPA, MJEPA), authors add either InfoNCE or EMA+stop-grad; whenever it is frozen (CrossJEPA, TI-JEPA, AlignJEPA's text side, Spa3R, Latent Denoising, GeoWorld-VLM), pure regression (smooth-L1 / L1+cos / cosine) suffices and no collapse is reported.
- Patch-level cross-modal correspondence is only used where geometry supplies it (Spa3R novel-view feature maps; TI-JEPA masked image patches; MJEPA intra-modal). Audio-video and image-caption works explicitly fall back to pooled targets for lack of token correspondence.
- Making JEPA-predicted embeddings the K/V of an LLM cross-attention is unexplored; the existing pattern is "JEPA pre-train, then freeze and cross-attend", with next-token loss only in the LLM stage.

### Gaps
- TI-JEPA's query/key assignment in its cross-attention aligners is not stated in the paper.
- CR-JEPA's predictor and target-encoder details were not extracted (abstract page only).
- No audio-visual or text-image JEPA was found that is applied to spatial or 3D tasks.

## Key question 6: Known failure modes — collapse with EMA targets, role of the predictor, momentum schedules, and L1 vs L2 vs cosine evidence

### Takeaway
Collapse is prevented in practice by the triad EMA target + stop-gradient + asymmetric narrow predictor (I-JEPA, V-JEPA, V-JEPA 2, Point-JEPA, MJEPA), but several papers document that EMA alone is insufficient or unstable (C-JEPA, AD-L-JEPA, CrossJEPA App. A) and three alternatives have emerged: a frozen teacher (SALT, CrossJEPA, Spa3R, Latent Denoising — no EMA needed), an explicit distribution regulariser (LeJEPA's SIGReg, AD-L-JEPA's VICReg variance), or a contrastive term (VL-JEPA, M3-JEPA, AlignJEPA). Momentum is almost always ramped from 0.995–0.999 to 1.0; V-JEPA 2 fixed it. On loss type the evidence is mixed: L1 ("more stable", V-JEPA), smooth-L1 (Point-JEPA, CrossJEPA), L2 (I-JEPA, JEPADepth), cosine (3D-JEPA, AD-L-JEPA, LLM-JEPA, GeoWorld-VLM); the only head-to-head ablations (VL-JEPA Table 7c, LLM-JEPA) favour cosine/InfoNCE over plain L2.

### Cited Findings
- I-JEPA: average L2 over M target blocks of patch representations (Sec. 3); EMA momentum 0.996 -> 1.0 linearly (App. A.1); "the EMA target-encoder is essential for training JEAs with ViTs" and the same was found for I-JEPA (Sec. 3); App. B lists stop-gradient, momentum encoders and asymmetric prediction heads as collapse-prevention methods citing Tian et al. for theory; predictor is a narrow ViT (384-d), depth 12 for ViT-L/H, 6 for ViT-B, 16 for ViT-G. Predictor ablations: depth 6 -> 64.0 vs 12 -> 66.9 (Table 12, ViT-L/16, 1% IN linear); width 384 -> 70.7 vs 1024 -> 68.4 (Table 14; *narrower is better*); predicting representations (66.9 @500 ep) vs pixels (40.7 @800 ep) (Table 7); masking target-encoder *output* rather than input 67.3 vs 56.1 (Table 11); single target block 9.0 vs 4 blocks 54.2 (Table 10). ImageNet linear ViT-H/14 79.3, ViT-H/16@448 81.1 (Table 1) — [arXiv 2301.08243](https://arxiv.org/html/2301.08243)
- V-JEPA: Eq. 1 minimises ‖P(E(x), Δy) − sg(Ē(y))‖₁; the authors "modify the image JEPA loss of Assran et al. (2023) to use ℓ1 regression, which we found to be more stable" (no L2 ablation shown); theory: the optimal ℓ1 predictor is the conditional median; EMA momentum 0.998 -> 1.0 linearly, schedules scaled to 112,500 iterations while stopping at 90,000 because the last 25% updated hyperparameters too aggressively (App. C, Table 8); collapse argument: a naive regression admits a constant-encoder solution; stop-gradient + EMA + predictor fix it, following Grill et al. 2020 (BYOL), Tian et al. 2021 (theory), Xie et al. 2021; the authors adapt the BYOL analysis to ℓ1 and hypothesise the EMA keeps the predictor near-optimal so the encoder must keep information. ### Inferences
- The predictor's job in EMA-JEPAs is to absorb the context->target mapping so that the encoder is not forced to become predictable-by-identity; the narrow-width result (I-JEPA Table 14) and the depth-helps result (I-JEPA Table 12, Point-JEPA Table 10) together suggest "deep but narrow" is the robust default. With a *frozen* teacher the predictor can be wider/deeper without collapse risk (V-JEPA 2-AC uses 24 x 1024; Spa3R uses 6 x 768).
- Evidence that EMA alone is fragile comes from three independent 3D/cross-modal settings (C-JEPA on images, AD-L-JEPA on LiDAR, CrossJEPA on image<->point). For a cross-modal geometry alignment, a frozen teacher (SALT/CrossJEPA/Spa3R pattern) is the lowest-risk choice, with an optional variance or SIGReg term if the student side is also a target.
- On L1 vs L2 vs cosine, there is no controlled comparison in a frozen-teacher geometry setting. The two existing ablations (VL-JEPA, LLM-JEPA) are both with trainable targets or tied LLM encoders and both disfavour raw L2; V-JEPA's "L1 more stable" is anecdotal; Spa3R and Latent Denoising hedge with L1+cos / normalised MSE. A reasonable prior is: normalise targets (or use cosine) when teacher feature norms vary across tokens, and prefer L1/smooth-L1 over L2 for robustness to multimodal targets (V-JEPA's median argument; the text-JEPA "centroid degeneracy" argument).

### Gaps
- No paper found that ablates EMA momentum values systematically (searched "I-JEPA predictor ablation collapse EMA target momentum"); only start/end values are reported.
- No controlled L1 vs L2 vs cosine ablation exists for a 3D or geometry JEPA (Point-JEPA, CrossJEPA, 3D-JEPA, AD-L-JEPA all use a single loss).
- C-JEPA's quantitative results and the JEPA-Paradox paper's numbers were not extracted (abstract pages only).
- The V-JEPA 2 fixed EMA coefficient value is not given in the fetched HTML.
