# Shared-space / aligned cross-attention for injecting a second modality (3D, depth, geometry, audio) into an LLM

Scope: 2022–2026 fusion architectures where (a) LLM hidden states and the injected modality are mapped into one joint space before attention, (b) an alignment loss (contrastive / predictive / distillation) is applied to that space or to the modality features, or (c) attention is made geometry-aware. Plus Flamingo-style gated cross-attention ablations and latents-vs-patch-keys evidence. All numbers below were read from the arXiv full text (HTML/ar5iv) unless marked otherwise; section/table numbers are those of the cited version. Items marked **[unverified]** come from search snippets or secondary summaries only.

Research date: 2026-10-26.

---

## KQ1. Are there VLM / 3D-LLM papers where cross-attention keys for 3D/depth features are trained with a contrastive or predictive alignment to the LLM query space ("aligned cross-attention", "query-key alignment", "alignment before fusion")?

### Takeaway
No paper found trains the *cross-attention key projection itself* with a contrastive/predictive loss against the LLM query space in a 3D-LLM. The closest designs are: (i) BLIP-2-style Q-Former (ITC aligns the *query outputs* that later become keys/prefix with text) and its 3D descendants (3D-LLM, LL3DA, Grounded 3D-LLM/CLASP), (ii) 2025–26 "representation supervision" works that align the LLM's *visual hidden states* (not keys) to a frozen 3D foundation model with cosine/MSE/InfoNCE (3DRS, Spatial Forcing, Dual-Pathway, PointAlign), and (iii) VLM-3R / SpaceMind / 3D-Mix, which put VGGT/CUT3R tokens as keys/values of a cross-attention whose queries are 2D visual tokens, trained only by the end task. So the specific idea "contrastively align K(3D) with Q(LLM) before/while fusing" appears to be an open gap as of 2026-10.

### Cited Findings
- **BLIP-2 (arXiv 2301.12597)**: stage-1 Q-Former trains 32 learned queries with image-text contrastive (ITC: each query output compared with the text [CLS]; max over queries), image-grounded text generation and image-text matching; stage 2 projects the query outputs with an FC layer and prepends them to a frozen LLM as soft prompts. Figure 5 (not a table) reports that *without* stage-1 representation learning both OPT and FlanT5 show "substantially lower performance on zero-shot VQA" and OPT suffers catastrophic forgetting; no numeric values are given in the text. — [BLIP-2 ar5iv](https://ar5iv.labs.arxiv.org/html/2301.12597)
- **3D-LLM (arXiv 2307.12981)**: 3D features are multi-view CLIP/ConceptFusion features lifted to points; sin/cos position embeddings of x,y,z (each D_v/3) are concatenated and *added* to the 3D features; location tokens are added to the vocabulary. Two backbones: BLIP-2 (Q-Former fine-tuned, LLM frozen except location tokens; 1408-d features) and OpenFlamingo-9B (perceiver + gated cross-attention + location-token embeddings fine-tuned; 1024-d features). Table 1 ScanQA-val: 3D-LLM(flamingo) B-1 30.3 / CIDEr 59.2 vs 3D-LLM(BLIP2-flant5) 39.3 / 69.4; Table 4 3DMV-VQA: flamingo 58.6 > BLIP2-opt 54.9 > BLIP2-flanT5 54.6. Table 7 (Flamingo backbone, ScanQA val): without perceiver CIDEr 58.9 / B-1 29.2; with perceiver 59.2 / 30.3. No ablation of position embeddings or location tokens. — [3D-LLM html](https://arxiv.org/html/2307.12981v1)
- **LL3DA (arXiv 2311.18651)**: Interactor3D uses 32 learnable 768-d querying tokens, 6 transformer layers; queries self-attend with text instruction and visual-prompt tokens, then cross-attend to a frozen scene encoder's 1,024 point tokens (256-d); outputs are linearly projected and prefixed to frozen OPT-1.3B. Table 3: direct injection of visual prompts 59.39 vs early fusion via the Q-Former 62.84 (ScanRefer C@0.5). No ablation on number of queries. — [LL3DA html](https://arxiv.org/html/2311.18651)
- **Grounded 3D-LLM (arXiv 2405.10370)**: CLASP pre-training: 150 object queries (initialised from Mask3D) cross-attend to a sparse-conv point-feature pyramid and bi-directionally cross-attend with BERT text; CMI outputs are projected into a shared text space (P_text, Q_text) and a mask space; S_text = P_text·Q_textᵀ with temperature 0.1; loss = mask (focal+Dice, Hungarian) + λ_cls·focal over phrase-to-region targets (the paper calls it contrastive; the stated form is sigmoid focal). Referent tokens are then *substituted into the LLM token sequence* (linear projection), not cross-attended. Table V: without CLASP, ScanRefer Acc@0.25/0.5 = 6.5/5.8; CLASP on all data (one-to-many) = 47.9/44.1; Multi3DRef F1@0.25/0.5 6.4/5.3 → 45.2/40.6. Bi-directional vs one-way interactor: 47.2 → 47.9 Acc@0.25 (Table VIII). — [Grounded 3D-LLM html](https://arxiv.org/html/2405.10370)
- **3DRS (arXiv 2506.01946, NeurIPS 2025)**: aligns the MLLM's *final-LLM-layer* per-pixel visual features (2-layer MLP projector) to frozen VGGT per-pixel features with negative cosine similarity, L = L_CE + L_align (implicit weight 1). Table 4 (LLaVA-NeXT-Video base; ScanRefer Acc@0.25/0.5, SQA3D EM): baseline 58.1/51.7, 58.6; SigLIP2 teacher 58.2/52.9; MAE 59.1/53.7; DINOv2 59.8/53.3; FLARE (3D) 62.1/55.7; VGGT (3D) 62.9/56.1, 60.6. Table 6 (which layer to supervise): last 62.9/56.1; 3rd-last 61.7/54.9; 5th-last 61.4/54.8; 10th-last 59.1/53.6. Table 3: gains replicate on LLaVA-OneVision (57.3→61.8 Acc@0.25) and Qwen2-VL (57.0→60.1). Multi-view correspondence score (cosine between features of different views that fall in the same 0.1 m voxel) correlates positively with downstream accuracy (Fig. 2, no numbers in text). — [3DRS html](https://arxiv.org/html/2506.01946v2)
- **Spatial Forcing (arXiv 2510.12276, VLA)**: aligns the VLA's *layer-24 of 32* visual tokens (BatchNorm + 2-layer MLP) to VGGT backbone features (with positional embedding added to the target) via cosine similarity; L = L_action + α·L_align. Table 2 (LIBERO avg SR): no alignment 92.7; align at layer 1 = 94.6, 8 = 95.7, 16 = 93.8, **24 = 96.9**, 32 = 94.8; targets at layer 24: SigLIP 94.0, DINOv2 94.1, VGGT w/o PE 94.7, VGGT + PE 96.9 (PE matters most on LIBERO-Long 84.4 → 94.2); reaches equal success 3.8× faster. The paper states "relatively deep but not the deepest layers" work best. — [Spatial Forcing html](https://arxiv.org/html/2510.12276v1)
- **3D-Mix for VLA (arXiv 2603.24393)** re-implements Spatial Forcing as one of nine VGGT-injection schemes on Qwen3-VL-4B: SIMPLER avg 58.85 vs base 57.81 (LIBERO 97.72 vs 96.5), i.e. a small gain relative to Gated Fusion (68.23). — [3D-Mix html](https://arxiv.org/html/2603.24393)
- **Ross3D (arXiv 2504.01901)**: predictive (reconstructive) supervision on the LLM's *visual output positions*: a small DiT denoiser reconstructs the VAE latents of 25 % masked views (cross-view) and a rendered BEV image (global-view); loss is diffusion MSE. Table 4 (Video-3D-LLM base; SQA3D EM / ScanQA CIDEr / ScanRefer Acc@0.25): baseline 58.6/102.1/58.1; +vanilla reconstruction 58.8/103.5/58.2; +cross-view 60.0/103.6/60.3; +global-view 61.6/105.6/58.8; both 63.0/107.0/61.1. Table 5: *adding* 3D point features as input instead gives only 59.1/102.4/57.8. — [Ross3D html](https://arxiv.org/html/2504.01901v1)
- **Dual-Pathway Geometry-Aware MLLM (arXiv 2605.25334)**: two groups of K=40 learnable queries (metric, structural) are appended after the visual tokens *inside the LLM's causal self-attention* with a task-decoupled mask (not cross-attention); EVG aligns a Perceiver-pooled projection of the LLM's last hidden states (patch + query positions) to Depth Anything V2 (metric) and VGGT (structural); loss = MSE + 0.01·InfoNCE (cosine, learnable temperature); experts are training-time only. Base Qwen3-VL-8B-Instruct. Table 2 (macro-avg over 7 spatial benchmarks): baseline 54.1; Q_s only 55.0; Q_s+Q_m no mask 55.1; full 55.7 (VSI-Bench 55.0 → 56.4). No with/without-EVG ablation. — [Dual-Pathway html](https://arxiv.org/html/2605.25334)
- **PointAlign (arXiv 2603.00412)** constrains "intermediate point cloud tokens within the LLM to align with visual input tokens via a consistency loss"; only a projector + LoRA trained; +2.08 pp avg classification (ModelNet40/Objaverse), +7.50 pp open-vocab Objaverse, +4.88 pp captioning. Loss form and layer **[unverified; abstract only]**; a search snippet claimed middle layers (~12–20) work best **[unverified]**. — [PointAlign abs](https://arxiv.org/abs/2603.00412)
- **VLM-3R (arXiv 2505.20279)**: Spatial-Visual-View Fusion: Q = SigLIP visual tokens H_v (729×1152), K/V = Concat(CUT3R geometry tokens F'_t 729×768, camera token z'_t 1×768), learned W_Q,W_K,W_V, residual H'_v = H_v + H_attn (residual stated only in App. A.1); 2-layer MLP projector (1152→3584→3584); tokens then concatenated with text into LLaVA-Video-7B-Qwen2 with LoRA r=128. Encoders frozen; fusion block, projector and LoRA trained *only by the end task*. Table 3 VSI-Bench avg: LLaVA-NeXT-Video fine-tuned (no 3D tokens) 57.74; w/o camera tokens 59.09; w/o geometry tokens 59.46; full 60.90. No cross-attention-vs-concat/add ablation. — [VLM-3R html](https://arxiv.org/html/2505.20279v2)
- **SpaceMind (arXiv 2511.23075)**: CGMF before the LLM: Q = P_Q(LN(f_v)) from InternViT visual tokens; K,V from LN(VGGT spatial tokens); camera-conditioned bias B_g = MLP([f_s, f_c]) added to K and V; query-independent token weights W_t = σ(MLP(f_s)) multiply V; camera token C prepended to K',V'; output gated by a camera-conditioned SwiGLU gate and added residually to f_v. Table 4 VSI-Bench avg: InternVL3-8B ft 63.07; + VGGT via shallow cross-attention 66.77; + twMLP 67.17; + geoMLP 68.73; full 69.58. Key space trained only by the end task. — [SpaceMind html](https://arxiv.org/html/2511.23075v2)
- **CrossViewer (arXiv 2605.18621)** **[unverified; search snippet]**: multi-view 2D MLLM with a cross-view alignment stage before fusion: one view's object tokens are queries and the matched view's tokens keys/values, plus a separate contrastive head that pools per-view tokens and pulls matching objects together on a unit hypersphere; motivated by "fusion alone does not enforce a stable identity structure in embedding space". — [search result](https://arxiv.org/pdf/2605.18621)
- **"From Alignment to Fusion in 3D Vision-Language" (arXiv 2609.28222)** **[unverified; search snippet]**: triple pairwise cosine alignment across multi-view image, point and voxel features applied before task-conditioned decoding. — [search result](https://arxiv.org/pdf/2609.28222)

### Inferences
- Every "alignment" loss found in 3D-LLMs is applied either (a) upstream of the LLM (Q-Former ITC, CLASP, PQ3D-style query decoders) or (b) to LLM hidden states as a side objective toward a *frozen 3D teacher* (3DRS, Spatial Forcing, Dual-Pathway). None targets the cross-attention key projection or ties keys to the LLM's query distribution. A JEPA-style "predict the key from the query" or contrastive Q–K alignment would therefore be novel in this literature.
- Where the alignment target is a 3D foundation model, the layer choice matters and is non-monotonic: Spatial Forcing finds layer 24/32 best (layer 32 worse than 8), 3DRS finds the last layer best among last/3rd/5th/10th-last. Both converge on "deep but not necessarily final".
- Alignment-to-teacher (3DRS: +4.8 Acc@0.25 ScanRefer; Ross3D: +4.4 SQA3D) gives larger gains than naively *adding* 3D point features as input (Ross3D Table 5: +0.5), which supports putting a predictive/contrastive objective on the geometry pathway rather than only feeding features.

### Gaps
- No paper found that applies a contrastive/predictive loss to the cross-attention *keys* in a 3D-LLM; "aligned cross-attention"/"query-key alignment" searches returned only 2D multi-view (CrossViewer) or encoder-side alignment.
- PointAlign loss form/layer and CrossViewer details could not be verified from full text.
- BLIP-2's stage-1 ablation is a figure only; no numbers available.

## KQ2. How do 3D-LLM, LLaVA-3D, Chat-Scene, Scene-LLM, LEO, 3D-VisTA, PQ3D, Video-3D LLM, GPT4Scene (and 2025–26 VGGT-based successors) bring 3D features into the LLM? Do any use cross-attention with explicit 3D position embeddings, and does cross-attention beat concatenation/addition or the reverse?

### Takeaway
Almost all 3D-LLMs inject 3D as *tokens concatenated into the LLM sequence* with 3D position embeddings *added* to the features (sinusoidal or MLP of xyz); cross-attention appears mainly in upstream query decoders (PQ3D, LL3DA, Grounded 3D-LLM, LLaVA-3D grounding head) or in pre-LLM fusion of VGGT/CUT3R tokens into 2D visual tokens (VLM-3R, SpaceMind). Direct comparisons are rare and mixed: Inst3D-LMM finds cross-attention > concatenation for 2D-into-3D object features; 3D-Mix (VLA) finds concat (60.4) > cross-attn (56.3) and gated per-token blending (68.2) best; SpatialStack finds additive per-layer residual injection works; 3D-LLM finds the Flamingo backbone worse than BLIP-2 on ScanQA but better on 3DMV-VQA. The clearest, consistently large effect is from *explicit 3D position encoding* (LLaVA-3D Scan2Cap 29.7→84.1; Video-3D LLM 31.0→83.8 C@0.5).

### Inferences
- "Cross-attention with explicit 3D position embeddings" exists in the literature only in *upstream* decoders (PQ3D: Fourier-PE'd queries + spatial self-attention; LLaVA-3D grounding head; Grounded 3D-LLM CLASP) and in pre-LLM fusion blocks (VLM-3R uses CUT3R tokens that already carry geometry; SpaceMind adds a camera-conditioned bias to K and V, which is a learned geometry-aware key modulation). No work inserts Flamingo-style gated cross-attention *inside* the LLM with 3D-PE'd keys and reports an ablation against concatenation.
- The only controlled in-LLM comparison (3D-Mix, VLA domain) ranks gated per-token blending > concat > cross-attn > middle-layer injection on out-of-domain SIMPLER, and shows pre-LLM cross-attention of 3D into 2D ("Visual Fusion", 4.69) can catastrophically fail without gating, while SpaceMind/VLM-3R make the same pre-LLM pattern work with residual + gating. This suggests gating/residual initialisation, not the attention mechanism per se, is the decisive factor.
- Chat-Scene's "separate tokens" (50.2) beating "early fusion into one token" (46.9) is evidence against collapsing 2D and 3D into a single token per object; it favours keeping modality-specific keys/tokens.

### Gaps
- No paper in this set reports a head-to-head of in-LLM gated cross-attention vs token concatenation for 3D scene QA/grounding at matched compute.
- LEO's Spatial-Transformer and with/without-2D ablations (App. G) were not present in the fetched text.
- Scene-LLM has no ablation removing xyz from the token feature.

## KQ3. Flamingo (gated xattn-dense) and successors (OpenFlamingo, IDEFICS/Idefics2, Otter, NVLM-X, Llama 3.2 Vision, Audio Flamingo): what do ablations say about gate initialisation, removing the gate, zero-init, and instability when cross-attention opens too fast?

### Takeaway
Flamingo's own ablation is the only published number for removing the tanh gate: overall −4.2 (70.7 → 66.5) with reported training instability; LLaMA-Adapter gives the most dramatic zero-init-vs-random ablation (ScienceQA 83.85 vs 40.77). Zero-initialised tanh gates are carried into Llama 3.2 Vision (HF `cross_attn_attn_gate = zeros(1)`, applied as `tanh()`), while NVLM-X and Audio Flamingo say "gated" without documenting init. Idefics2 reports that cross-attention is more robust than fully-autoregressive fusion with frozen backbones (66.7 vs 60.3) but loses under LoRA (67.3 vs 69.5), and that unfreezing the fully-autoregressive model causes loss divergence. Flamingo also reports that enlarging the Perceiver Resampler "lead to unstable training".

### Cited Findings
- **Flamingo (arXiv 2204.14198), Sec. 2.2**: GATED XATTN-DENSE blocks inserted between frozen LM blocks; keys/values from vision (Perceiver output), queries from language; output multiplied by tanh(α) with layer-specific α initialised to 0 (citing ReZero) so the model equals the LM at init, which "improves training stability and final performance". — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)
- **Flamingo Table 3** (Flamingo-3B, 4-shot dev; Overall): baseline 70.7; (iii) **no tanh gating 66.5** (COCO 86.5→78.4, VATEX 53.4→47.5) with the text also reporting training instability; (iv) vanilla xattn (standard decoder cross-attention) 66.9; grafting 63.1; (v) xattn every layer 70.7, every 2nd 68.2, every 4th 68.8 (−1.9, 66 % faster), single middle 59.8; resampler Perceiver 70.7 vs MLP 66.6 vs Transformer 66.7; (viii) LM frozen 70.7 vs fine-tuned 62.7 vs random init 57.8. — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)
- **Flamingo Appendix A.1.2, Figure 6**: |tanh(α)| per layer of Flamingo-3B's 24 LM layers vs training progress: values grow quickly from 0 ("All layers of the frozen LM stack seem to utilize the visual information") and "seem to grow with the depth", with the caveat that activation scale also varies with depth. — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)
- **Flamingo Table 10 (App. B.3.1)**: Resampler small 67.9 / medium (default) 70.7 / large 69.0, and "we observed that increasing the size of the Perceiver Resampler lead to unstable training"; multi-image attention to all previous images 63.5 vs only-last (default) 70.7 (−7.2); co-training LM on MassiveText (pretrained) 68.6; vision encoder unfrozen (pretrained) 68.1, random init 61.4. — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)
- **LLaMA-Adapter (arXiv 2303.16199), Sec. 3.2 & Table 5**: adaption prompts prepended as K/V in the top L layers; a per-head learnable gate g (tanh-bounded, "initialized by zero") scales the prompt-softmax term while the word-token softmax is untouched; multimodal variant *adds* a projected CLIP image token to the prompts. - **OpenFlamingo (arXiv 2308.01390)**: frozen CLIP ViT-L/14, trainable Perceiver resampler, "dense cross-attention modules" (gating not mentioned) at intervals 1 (3B), 2 (4B), 4 (9B); weight decay 0.1 on cross-attention layers; `<image>`/`<|endofchunk|>` embeddings trainable. Table 5: freezing those embeddings drops 0-shot COCO 46.5→41.9 and VQAv2 17.6→5.5. No instability or gate-init discussion; no cross-attention-frequency ablation. — [OpenFlamingo html](https://arxiv.org/html/2308.01390v2)
- **NVLM (arXiv 2409.11402)**: NVLM-X uses 10 gated X-attention layers (every 6 LLM layers for 34B, every 8 for 72B) with *no* Perceiver; pretraining trains only X-attn (LLM frozen), SFT trains X-attn + LLM (Tables 10–11). Whether the gate is tanh/zero-init is **not stated in the fetched text [unverified]**. - **Llama 3 (arXiv 2407.21783), Sec. 7.2**: "The cross-attention layers are applied after every fourth self-attention layer"; they use GQA; ≈100B parameters for the 405B model; image encoder ViT-H/14 (630M) gets 8 extra *gated* self-attention layers (850M) "to learn alignment-specific features" and is *not* frozen; LM frozen during image SFT "to maintain text-only performance"; numerical instability handled by FP32 gradient accumulation; sequence parallelism in the image encoder. No gate-init statement. — [Llama 3 html](https://arxiv.org/html/2407.21783)

Vision global-transformer gates `gate_attn`/`gate_ffn` are initialised to π/4 in `__init__` (tanh(π/4)≈0.66) but `_init_weights` overwrites them with `normal_(std)`. — [HF modeling_mllama.py](https://raw.githubusercontent.com/huggingface/transformers/main/src/transformers/models/mllama/modeling_mllama.py)
- **Audio Flamingo (arXiv 2402.01831)**: ClapCap sliding-window encoder (7 s windows, 5.25 s overlap, ≤16 windows), 3 trainable audio self-attention layers, tanh-gated xattn-dense layers "prepended to each LM block" of OPT-IML-MAX-1.3B (24 blocks); no gate-init statement; footnote 2: "unfreezing the audio encoder caused training instability" so it stays frozen; no cross-attention-vs-prefix ablation (only argued by FLOPs). — [Audio Flamingo html](https://arxiv.org/html/2402.01831v3)
- **3D-Mix (arXiv 2603.24393)** again: the ungated pre-LLM "Visual Fusion" (3D cross-attended into 2D tokens) collapses to 4.69 SIMPLER vs base 57.81, while learnable per-token gates give 68.23. — [3D-Mix html](https://arxiv.org/html/2603.24393)
- **OmniSpace (arXiv 2606.22617)** zero-initialises both the 1×1 conv that adds Plücker-ray pose embeddings to visual features and the output projection of its epipolar attention block "so the model starts out behaving like the base MLLM". — [OmniSpace html](https://arxiv.org/html/2606.22617v3)

### Inferences
- Across Flamingo, LLaMA-Adapter, Llama 3.2 and OmniSpace, the common recipe is: new pathway output × tanh(0)=0 (or a zero-init projection) so the pretrained LM is exactly preserved at step 0; the one published no-gate ablation (Flamingo) costs ~4 points and instability, and the random-init ablation (LLaMA-Adapter) costs ~43 points.
- Flamingo Fig. 6 implies gate magnitudes are a cheap, already-used monitor of whether and when each layer "opens" to the modality; nothing in the literature reports *how fast* opening is harmful, only that non-zero/no-gate starts hurt.
- Idefics2's result (cross-attention wins only when the LM is frozen) and NVLM's (decoder-only wins on OCR at 72B scale, cross-attention wins on throughput) together indicate cross-attention is the safer choice for a frozen-LM retrofit, but the latent/key count must not be compressed for fine-grained spatial tasks (see KQ4).

### Gaps
- IDEFICS-1 (OBELICS) and Otter were not fetched; no gating ablations are known from them (Otter builds on OpenFlamingo, so inherits its design) **[unverified]**.
- NVLM's gate form/initialisation is undocumented in the sections fetched.
- No paper quantifies "cross-attention opening too fast" (e.g., gate learning-rate or warm-up ablations).

## KQ4. Latents vs patch keys: how does compressing visual tokens into few latents (Perceiver Resampler, Q-Former) affect fine-grained or spatial tasks (Flamingo, Idefics2, NVLM, Honeybee, Cambrian-1)?

### Takeaway
Evidence is consistent that *global* latent resamplers (Perceiver/Q-Former) lose locality and hurt spatial/OCR tasks: Honeybee's Resampler scores 43.9–45.6 on spatial benchmarks vs 52.6–56.3 for linear/convolutional locality-preserving projectors at the same token count; Cambrian-1's Resampler drops OCR&Chart to 27.1 vs 50.1 for concat and 55.5 for spatially-structured SVA; NVLM removed the resampler after its Flamingo-1.3B OCR fine-tune could not overfit with it (loss ≈0.4 vs →0 without). Idefics2 finds 64 latents ≥ 128 latents on its 4-benchmark average but needs 320 tokens (image splitting) for TextVQA/DocVQA (+2.6 / +6.7). Flamingo itself found larger resamplers unstable.

### Cited Findings
- **Flamingo**: Perceiver Resampler outputs a fixed 64 tokens; K/V = concatenation of visual features *and* latents ("slightly better" than DETR/Perceiver style); learned temporal (not spatial) position encodings; Table 4: 6 layers, hidden 1536, 16 heads. Resampler small/medium/large = 67.9/70.7/69.0 overall; larger → "unstable training". — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)
- **Idefics2 (arXiv 2405.02246)**: Table 4: Perceiver 64 tokens 71.7 vs 128 tokens 71.2 ("no gains above 64"); learned pooling +8.5 over unpooled (729→64 tokens). Table 11: linear 44.5, mapping network 51.8, Perceiver 60.3. Table 12: Perceiver depth 1/3/12 → 69.3/68.6/69.0. Table 9: 64 vs 320 tokens (image splitting): TextVQA 70.4→73.0, MMMU 43.5→43.0, MathVista 51.6→51.4; Table 15: DocVQA 67.3→74.0, VQAv2 80.8→81.2. — [Idefics2 html](https://arxiv.org/html/2405.02246)
- **NVLM (arXiv 2409.11402), Sec. 3.2/4.3 & App. C**: NVLM-X uses no Perceiver; Flamingo-1.3B fine-tuned on 30K OCR documents: with resampler the training loss plateaued at ~0.4; with the resampler removed (only cross-attention trained) loss reached 0 at the same iteration; authors hypothesise latent attention "may shuffle the spatial information among the image patches". NVLM-X keys = 256 pixel-shuffled tokens per 448² tile × up to 7 tiles. — [NVLM html](https://arxiv.org/html/2409.11402)
- **Honeybee (arXiv 2312.06742)**, Table 3 (spatial-understanding subset: MME-POS, MMB-SR/OL/PR, SEED-SR/IL; AvgN): Resampler-144 43.9; C-Abstractor-144 53.5; Linear-256 52.6; Resampler-256 45.6; C-Abstractor-256 56.3. Table 8 overall AvgN: Linear-256 70.0, Resampler-144 64.2, C-Abstractor-144 70.6. Sec. 1/3.2.1: the Resampler "primarily focus[es] on a few regions" and lacks locality awareness (Fig. 3). — [Honeybee html](https://arxiv.org/html/2312.06742)
- **Cambrian-1 (arXiv 2406.16860)**: SVA = L×L grid of learnable latent queries, each cross-attending only to its own m_k×m_k sub-region of every encoder's feature map (spatial inductive bias), optionally re-inserted D times inside the LLM (stride 3). Table 4 (4 encoders; General/Knowledge/OCR&Chart/Vision-centric): Concat 67.2/48.9/50.1/52.6; **Resampler 63.1/46.5/27.1/42.6**; SVA-no-multi-agg 68.0/49.5/55.2/52.6; SVA 68.5/49.7/55.5/53.2. Table 5 (one CLIP ViT-L, 576→36 tokens): Interp+MLP 63.4/43.8/28.1/43.7; C-Abstractor 64.4/42.8/26.1/44.3; LDPv2 62.5/43.9/28.7/43.9; SVA 65.5/44.5/31.4/46.9. Table 6 (OCR&Chart): multi-layer aggregation in the LLM 52.4→53.3; G=1/2/3 → 52.4/52.6/53.1. — [Cambrian-1 html](https://arxiv.org/html/2406.16860)
- **3D-LLM Table 7**: on 3D features the Flamingo perceiver gave only +0.3 CIDEr (58.9→59.2) and slightly worse B-4/EM. — [3D-LLM html](https://arxiv.org/html/2307.12981v1)
- **LLaVA-3D Table 10/11**: more 3D tokens help monotonically up to a point (voxel 0.4/0.3/0.2 m → ScanQA 24.1/25.9/27.0; FPS 576/1024 → 25.7/26.3; views 16→20 saturate). — [LLaVA-3D html](https://arxiv.org/html/2409.18125)
- **Flamingo Table 10 (ii)**: letting text attend to *all previous* images' keys instead of only the last drops overall 70.7→63.5; the authors attribute it to lack of disambiguation between images. — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)

### Inferences
- For a spatial-reasoning target (VSI-Bench-style distances/directions), the evidence favours *full patch-grid keys* (NVLM-X style, or per-position fusion as in Spatial-MLLM/SpatialStack) or a spatially-structured query grid (Cambrian SVA) over a global Perceiver/Q-Former; the penalty of global latents is largest on OCR/position tasks (Cambrian OCR&Chart 27.1 vs 55.5; Honeybee POS 75 vs 135).
- Idefics2's "64 latents suffice" result is on coarse VQA/captioning averages; its own TextVQA/DocVQA splitting results show the compressed latent set is the bottleneck for fine-grained tasks.
- Flamingo's multi-image result (attending to all previous images hurts) suggests that when keys from multiple views/frames are exposed, they need explicit view/position disambiguation (tile tags in NVLM, 3D PE in Video-3D LLM) rather than an undifferentiated key pool.

### Gaps
- No paper directly ablates "number of cross-attention keys" (latents vs full grid) on a *3D spatial* benchmark such as VSI-Bench; the closest are Honeybee/Cambrian (2D spatial subsets) and NVLM App. C (OCR loss curves only).
- MM1 (arXiv 2403.09611) and DeCo (arXiv 2405.20985) likely contain relevant connector/token-count ablations but were not fetched **[unverified]**.

## KQ5. Geometry-aware attention when injecting 3D into a VLM/3D-LLM: 3D position encodings, epipolar/ray attention, depth-biased attention, relative-geometry attention

### Takeaway
Inside LLMs, geometry awareness is almost always implemented as *additive 3D position encodings on tokens* (LLaVA-3D, Video-3D LLM, 3D-LLM, PQ3D, Scene-LLM), with very large effects on position-dependent tasks and near-zero effect on QA. True geometry-aware *attention* (relative transforms or epipolar masks) is documented in NVS transformers (GTA) and driving MLLMs (OmniSpace, S4-Driver) rather than in indoor 3D-LLMs; SpaceMind's camera-conditioned key/value bias is the closest VSI-Bench example.

### Cited Findings
- **Video-3D LLM Table 3**: no 3D-PE vs sinusoidal 3D-PE added to patch tokens: Scan2Cap C@0.5 31.03→83.76; ScanRefer Acc@0.5 50.84→51.72; ScanQA EM 30.03→30.09; MLP PE 76.23. — [Video-3D LLM html](https://arxiv.org/html/2412.00493v2)
- **LLaVA-3D Table 9**: 2D→3D patches (MLP PE added): Scan2Cap 29.7→84.1; MMScan QA 42.1→55.4; ScanQA 29.4→29.8; SQA3D 59.8→60.1. — [LLaVA-3D html](https://arxiv.org/html/2409.18125)
- **GTA (arXiv 2310.10375, ICLR 2024)**: each token carries camera extrinsic c∈SE(3) and 2D patch position as SO(2)×SO(2) angles; representation ρ (rigid transform, Wigner-D, multi-frequency 2D rotations) is applied *relatively*: queries × ρᵀ, keys and values × ρ⁻¹, output mapped back; unlike RoPE it also transforms V (removing the value transform: CLEVR-TR PSNR 38.99→36.54, MSN-Hard 24.58→23.77, Table 5). Table 12 CLEVR-TR PSNR: APE 33.66, RPE 36.06, SRT (ray embeddings) 33.51, RePAST (ray embeddings in attention) 37.27, GTA 39.63; Table 4: MLN 32.48, GBT 35.63, FM 37.23, RoPE+FTL 38.18, GTA 38.99; MSN-Hard: SRT 24.27, RePAST 24.48, SRT+GTA 25.72; reaches RePAST's PSNR in ~1/6 of training steps (Fig. 6); reference-frame invariant (Table 13). Needs known/estimated poses. — [GTA html](https://arxiv.org/html/2310.10375v3)
- **OmniSpace (arXiv 2606.22617, driving MLLM)**: Camera Pose Injector: per-pixel Plücker ray (o×d, d) → zero-init 1×1 conv, *added* to 2D visual features before the LLM; Multi-view Epipolar Attention (Eq. 2): a token attends to all tokens of its own view plus only the tokens on its (3×3-dilated) epipolar line in other views; zero-init output projection, residual; applied to visual tokens before the MLLM backbone. Table 4 (nuScenes open-loop planning L2 / collision % / intersection %): baseline 0.36/0.36/3.05; epipolar only 0.33/0.23/2.84; pose only 0.32/0.24/2.80; 3D distillation only 0.30/0.23/2.92; all 0.28/0.19/1.27. Table 7: vanilla cross-view attention 0.29/0.24/1.96 vs epipolar 0.28/0.19/1.27. Table 6: no ray 0.29/0.22/2.66, naive ray 0.29/0.24/2.50, Plücker 0.28/0.19/1.27. (Baseline rows differ between Tables 4 and 6/7.) — [OmniSpace html](https://arxiv.org/html/2606.22617v3)
- **S4-Driver (arXiv 2505.24139)** **[unverified; search snippet]**: adds a pairwise-3D-distance term into the MLLM self-attention softmax, Attn = Softmax(QKᵀ/√d − b(D))V, over a sparse-volume spatio-temporal representation. — [S4-Driver abs](https://arxiv.org/abs/2505.24139)
- **SpaceMind** (see KQ1): camera-conditioned additive bias on K and V and camera token prepended to the key/value memory; cumulative ablation 66.77 → 68.73 (+1.96 over shallow cross-attention) from the geometry MLP bias, 69.58 with the camera-conditioned SwiGLU output gate. — [SpaceMind html](https://arxiv.org/html/2511.23075v2)
- **3D-VisTA / LEO / Inst3D-LMM**: pairwise distance/angle biases in *object-level* self-attention (ViL3DRel-style); Inst3D-LMM Table 4: without spatial relations 35.6/29.8 → with 3D-ISR 48.3/44.1 ScanRefer. — [Inst3D-LMM html](https://arxiv.org/html/2503.00513); [3D-VisTA html](https://arxiv.org/html/2308.04352v1); [LEO html](https://arxiv.org/html/2311.12871v3)
- **PQ3D**: segment mean coordinate → MLP PE added to features; queries carry Fourier PE of FPS coordinates; spatial self-attention over queries. — [PQ3D html](https://arxiv.org/html/2405.11442v2)
- **Spatial Forcing**: adding positional embeddings to the VGGT *target* features in the alignment loss raised LIBERO avg 94.7→96.9 (LIBERO-Long 84.4→94.2). — [Spatial Forcing html](https://arxiv.org/html/2510.12276v1)

### Inferences
- The PE-on-tokens results split tasks cleanly: anything requiring localisation (captioning with boxes, grounding, MMScan) gains 10–55 points; free-form QA gains <1. A JEPA/cross-attention design should therefore be evaluated on localisation-sensitive metrics, not ScanQA/SQA3D alone.
- GTA's finding that transforming *values* as well as Q/K matters (−2.4 PSNR without) is a concrete design hint for geometry-aware cross-attention: a relative-pose transform on the key/value side is more than a positional bias.
- OmniSpace demonstrates zero-init geometry injection + epipolar masking in an MLLM with monotone gains, but only on driving planning metrics; no indoor VSI-Bench analogue was found.

### Gaps
- No indoor 3D-LLM with epipolar/ray-masked attention or depth-biased attention inside the LLM was found (searches returned driving MLLMs and diffusion NVS models only).
- S4-Driver's bias details and ablations are unverified.

## KQ6. Attention-retrieval diagnostics as a training monitor (does visual token i attend to its own region's key?)

### Takeaway
No paper was found that uses "does query i retrieve its own region's key" as a *training-time monitor*. The nearest documented diagnostics are Flamingo's per-layer tanh-gate magnitude curves (Fig. 6), 3DRS's cross-view voxel-correspondence cosine score (which correlates with downstream accuracy), Spatial Forcing's depth-probing of visual embeddings, and evaluation-time attention-coverage metrics in interpretability papers.

### Cited Findings
- **Flamingo Fig. 6 (App. A.1.2)**: tracks |tanh(α)| of each of 24 gated layers over training as evidence that every layer uses visual input. — [Flamingo ar5iv](https://ar5iv.labs.arxiv.org/html/2204.14198)
- **3DRS Sec. 3 / Fig. 2**: multi-view correspondence score = mean cosine similarity between MLLM visual features from different views that fall in the same 0.1 m voxel; samples split into quartiles show accuracy rising with the score on all five datasets (figure only, no numbers in text). Table 5: training with an explicit correspondence loss gives 60.1/53.3 ScanRefer vs 62.9/56.1 with VGGT supervision vs 58.1/51.7 baseline (column mapping flagged as uncertain by the extraction). — [3DRS html](https://arxiv.org/html/2506.01946v2)
- **Spatial Forcing Sec. 2.2 / Fig. 3**: linear depth probing of frozen VLA visual embeddings shows no meaningful depth structure without alignment and clear structure with it (qualitative only). — [Spatial Forcing html](https://arxiv.org/html/2510.12276v1)
- **Honeybee Fig. 3**: visualises which image regions the Resampler's latents attend to (a few dominant regions) as a diagnostic of locality loss. — [Honeybee html](https://arxiv.org/html/2312.06742)
- **"Looking to Learn" (arXiv 2510.08470)**: per-token/per-feature learned gates between text self-attention and cross-attention outputs; reports gate-value statistics by part-of-speech (Kruskal-Wallis H=154.91, p<0.001) rather than attention-retrieval; its image is a single global embedding, so no region-level analysis. — [Looking to Learn html](https://arxiv.org/html/2510.08470v1)
- Search snippets **[unverified]** describe evaluation-time attention-coverage metrics (fraction of a ground-truth box receiving high cross-attention in MedGemma middle layers) and grounding-head identification (~1.7–2.6 % of heads causally responsible for text-to-region grounding), but none as a training monitor. — [search results](https://arxiv.org/pdf/2602.21428)

### Inferences
- A self-retrieval diagnostic (argmax over keys of softmax(q_i·K) == i, or rank of the co-located key) would be new as a monitor; the published precedents (gate magnitudes, voxel-correspondence cosine, depth probing) suggest pairing it with a geometry-grounded proxy such as 3DRS's correspondence score, which already has evidence of correlating with task accuracy.
- Flamingo Table 10 (ii) (attending to all previous images hurts by 7.2) implies that key-retrieval ambiguity across views is a real failure mode worth monitoring when exposing multi-view keys.

### Gaps
- No source found for an attention-retrieval or key-hit-rate metric used during training of a VLM or 3D-LLM; this is a gap in the literature as searched (two targeted queries).

### Inferences
- Only BLIP-2/3D-LLM, 3D-VisTA, Grounded 3D-LLM, Ross3D, 3DRS, Spatial Forcing and Dual-Pathway train any part of the injected-modality representation with a loss other than the end task; of these, none applies it to cross-attention keys inside the LLM.

### Gaps
- IDEFICS-1, Otter, MM1, DeCo, Any2Point, Point-LLM/PointLLM, Chat-3D v1, 3D-LLaVA and SceneVerse were not fetched; their designs are known only from secondary summaries and are omitted rather than recorded unverified.
